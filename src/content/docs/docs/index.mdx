Welcome to the Surface Labs documentation. Surface Labs is a node-based
procedural texture authoring application: you build textures and materials by
connecting nodes into a graph and adjusting their parameters.

These pages describe how to get started, what the application does, and where to
get help. Use the links below or the sidebar to navigate.
