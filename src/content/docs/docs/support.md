## Sending diagnostics with a report

**Settings → General → Export Diagnostics…** bundles crash dumps, session
logs, any projects that failed to load, and the open project with its autosave
into a single zip, then hands it to a save dialog. Attach that zip to your
email. It is also the way to get diagnostics off an iPad, where the crash
folder is otherwise only reachable through the Files app.

After a crash the Project Hub raises a toast with an **Export…** button that
writes the same kind of zip. It offers each crash once, so if you let it pass,
use Export Diagnostics… instead. See
[Autosave & Recovery](/docs/help/autosave-and-recovery/).
