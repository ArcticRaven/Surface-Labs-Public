## Create your first texture

Surface Labs works by connecting nodes into a graph. In general terms:

1. Start a new project or graph.
2. Add one or more nodes that generate a base pattern.
3. Connect nodes together to combine and modify the result.
4. Connect the final node to an output to see the generated texture.
