In Surface Labs, a texture is built from **nodes** connected into a graph. Each
node takes zero or more inputs, performs an operation, and produces an output
that can be passed to other nodes.

## Node categories

Nodes generally fall into a few broad kinds:

- **Generators** — produce a base pattern from parameters (for example, noise or
  a gradient).
- **Filters and adjustments** — take an input and modify it.
- **Combiners** — merge two or more inputs into one (for example, blending).
- **Outputs** — mark the final result of a graph.
