## 1.2.0

A native Rust engine

- Node evaluation, custom shaders and the export encoders run on a native Rust
  engine: Direct3D 12 on Windows, Metal on macOS and iPad, Vulkan on Linux.
- Authoring up to 8192 by 8192 in 8, 16 or 32-bit float. 8K is desktop-only for
  now.
- Most nodes render in under a millisecond, and a heavy graph stays under two.

New nodes

- Erosion. Hydraulic and thermal weathering that moves material instead of
  blurring it, so what one area loses shows up downstream. Around 230 ms for 80
  steps at 2048 square on an RTX 3070.
- Distance Field, computed by jump flooding and seamless across the tile edge.

Authoring

- A full GLSL editor for custom nodes.
- A built-in MCP server.

Also in 1.2

- A memory guard that warns before you run out.
- Fonts used by Text nodes embed into the project, so type renders the same on
  every machine.
