## 1.2.3

News in the hub

- The News card in the sidebar is now two tabs. Comms carries announcements
  published from the website — releases, devlogs, sales and notices — so news
  arrives without waiting for an app update. Changes is the release notes that
  were already there.
- Announcements are dated newest first, with pinned entries on top and a dot on
  the ones not yet read. Posts can be scheduled ahead of time, and everyone sees
  them at the same moment regardless of timezone.
- A quiet "available" pill appears in the card header when a newer build exists,
  and the Changes tab shows what is in a version not yet installed, so it is
  possible to see what a newer release contains before deciding to update.
- Everything works offline. The last announcements received stay on screen,
  release notes for the installed version ship with the app, and a failed check
  looks like "nothing new" rather than an error.
- Announcements can be turned off entirely in Settings, General, along with a
  control to clear what has been cached.
- The website button in the sidebar now opens the real site instead of a
  placeholder address that went nowhere.
